# Useful_AI_Tools

This repository contains a curated list of useful AI tools that can help users work more efficiently and boost productivity.

List of useful AI tools:

1. NotebookLM: Summarises any PDF, scanned documents and generates PDF, videos, podcasts, mind maps and many more.

2. Wispr flow AI: Voice-to-text AI that turns speech into clear polished writing in every app.

3. Stitch AI: UI/UX design.

4. Google AI Studio: Frontend and backend (give prompt and it builds for you).

5. Gemini/ChatGPT: Image creation.

6. Claude AI: Full-functioning applications.

7. Julius AI: Data analysis AI tool that can be used to download excel dashbboards with suitable prompts.

8. AIPRM for ChatGPT extension: Adds a large-library of pre-written prompts and prompt management features to ChatGPT.

9. ChatGPT: ChatGPT voice-time for real time mock interviews.

10. Comet (Agentic AI browser): Efficient searches based on prompt (job searches via LinkedIn with suitable prompt).

11. n8n (Personal Agentic AI employee): Fair-code workflow automation platform with native AI capabilities.

12. Dispatch mode feature in Claude: Pairs mobile app with desktop, allowing us to assign, monitor and approve tasks or workflows away from our computers.
